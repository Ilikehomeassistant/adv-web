# ADV on the web

Play [ADV](https://github.com/Ilikehomeassistant/adv-carts) carts in your browser: **https://ilikehomeassistant.github.io/adv-web/**

On a phone it's the handheld: tap the buttons (or arrows, Z = A, X = B, Enter = START, Shift = SELECT).
On a PC it's the console and its cart library: drag a cart into the slot and type RUN.
Get carts from the online list, or open a picture of a cart. Add `?mode=phone` or `?mode=pc` to choose.

This folder is the built site (made from the `web` folder of the ADV project).
