# ADV on the web

Play [ADV](https://github.com/Ilikehomeassistant/adv-carts) carts in your browser: **https://ilikehomeassistant.github.io/adv-web/**

Arrows move, Z is A, X is B, Enter is START, Shift is SELECT (or tap the buttons on a phone).
Get carts from the online list, or open a picture of a cart.

This folder is the built site (made from the `web` folder of the ADV project).
