# ADV on the web

**https://ilikehomeassistant.github.io/adv-web/**: play ADV carts in your browser.

- **On a PC:** the desk. The console is wired to a screen of online carts: click one (or drag it to the slot) and type RUN.
- **On a phone:** the Game Boy-style handheld.
- **The Developer Kit** (`devkit.html`, PCs only): the off-white dev kit console with its editors. Make your own carts and upload them to [adv-carts](https://github.com/Ilikehomeassistant/adv-carts).
- **Downloads:** ADV for Windows, the Developer Kit for Windows, and ADV for Android are on the [releases page](https://github.com/Ilikehomeassistant/adv-web/releases/latest).

Add `?mode=phone` or `?mode=pc` to choose which you get.

This folder is the built site (made from the `web` folder of the ADV project).
